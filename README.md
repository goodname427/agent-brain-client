# Agent Brain Client

Agent Brain Client 是 macOS 和 Windows 上的 Agent Brain 设备端。它让 Codex 和 CodeBuddy 连接 Agent Brain Server，通过 MCP 保存、检索记忆，并通过宿主 Hook 采集已授权的未来会话。

## 开始使用

把本仓库链接发给本地 Codex 或 CodeBuddy，或先读[安装引导](BOOTSTRAP.md)。引导按设备平台和安装状态选择首次接入、更新或恢复。首次接入使用用户选择的 HTTPS Server 地址和本机隐藏输入或已授权的密钥文件，不在聊天里发送密钥。

接入后从 [Onboarding](BOOTSTRAP.md#onboarding)核对连接及获准的来源。日常使用见[记忆使用说明](https://github.com/goodname427/agent-brain-client/blob/main/docs/reference/memory-behavior.md)与[日常维护](https://github.com/goodname427/agent-brain-client/blob/main/docs/installation/maintenance.md)。

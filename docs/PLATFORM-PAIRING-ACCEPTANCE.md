# 跨平台配对与安装验收

状态：2026-10-12 Windows 兼容边界现在纳入安装设计；Windows 适配尚未实现或验收。本记录不改变当前 Mac 试点、发布渠道、平台许可、凭据信任或安装政策。

## 协议与平台职责

HTTPS 配对 prepare/confirm、服务端签发的设备授权、内容协议、CAS、request ID 幂等、离线 outbox 与恢复语义保持共享。配对协议不得依赖 macOS、login Keychain 或客户端拥有管理 SSH 权限。

系统凭据保护、可信输入界面、依赖配送和原生 Agent 安装分别由平台适配实现。当前实现使用 macOS login Keychain 和已固定 helper，当前平台政策只覆盖审阅过的 Mac；不能把共享协议或合成测试宣称为 Windows 已支持，也不能让 Windows 绕过现有平台校验、复用 Mac profile 或落入明文凭据回退。

## 首次安装与邀请码交付边界

当前受控 Mac 试点中，维护执行器经已有授权的管理 SSH 私有管道取得短期邀请，并预填专用原生确认窗口。这是本次维护流程的安全交接，不是通用产品的配对依赖。

普通新客户端应能在没有管理 SSH 密钥、sudo 权限、服务器 shell 或 GitHub/Data 凭据的情况下独立安装和配对。管理侧负责经批准范围签发并安全交付短期邀请；普通客户端通过可信本地输入和 HTTPS 消耗它。当前 Mac 仓库脚本复用现有安全输入，独立 Server 私有工具复用既有 issuer；实际新设备交付仍需具体对象批准和首次安装验收。服务器地址通过可信、无嵌入凭据的配置提供，并保持 TLS 身份校验；邀请码与持久 token 不得通过聊天、命令行参数、环境变量、剪贴板或日志搬运。不得给普通客户端增加邀请签发/管理能力。

邀请始终短期有效，设备 token 按已批准政策有效至撤销；服务端决定所有者、范围与授权，不由客户端选择任意 Data 根或扩大权限。新 HTTPS 产品的业务、配对和同步保持 HTTPS，Server 的公开 Client 发布目录使用何种 Git 传输与用户配对协议分开。

## Windows 待办及产品验收

- 核验并实现 Windows 系统凭据后端；明确当前用户、安装程序与 Agent/helper 的访问边界、允许的调用者、稳定身份与升级规则。不能照搬 macOS 的 ACL 保证，也不能只因调用系统 API 成功就声称已保护。
- 交付 Windows 可信输入和安装/卸载流程；明确运行依赖、包完整性、支持架构、Agent 原生注册与权限提示。普通新设备没有管理 SSH/预装开发工具时仍需按实际交付方案完成；签名和系统信任另按具体方案审阅。
- 端到端验收独立取得邀请、仅一次安全输入、HTTPS prepare/confirm、系统保护存储、实际 Agent 工具发现与内容读写。模型只收到状态回执，不能取得邀请或持久 token。
- 覆盖取消、过期、系统凭据保护不可用/拒绝、锁定、程序升级、重启和丢失回执恢复；复用原 nonce/request ID 和同一设备授权，不重复签发或覆盖无关凭据。
- 验收按设备撤销及恢复/卸载后处理，区分删除本机项与服务端撤销；保留其他设备授权、用户内容和未确认队列。迁移与恢复只按匹配后像处理，不覆盖外部修改。
- 验收 Windows 与 Mac 使用同一所有者的当前/未来 Memory、Rule、Skill 内容；保持 read/put、CAS、幂等及离线冲突保留。普通设备不得新增 delete/admin/启用权限，新 Rule/Skill 默认 disabled，既有启用状态按政策保留。
- 使用真实 Windows 新设备验证系统保护、裸机安装、重启恢复、可信 UI 与实际模型调用；合成测试只证明共享协议兼容。Windows 发布和服务端平台政策必须形成独立冻结清单与准确批准范围。

## 当前执行顺序

先完成已批准 Mac 主线；用户说开始前不签发邀请、不打开计时窗口。首次安装采用仓库脚本：准备依赖及无凭据配置、确认服务器/范围、一次现有安全输入、既有 HTTPS 安装事务和启动 updater；不要求 Apple 分发身份、公证或 `.app`。Windows 共享 profile/发布政策/安装作用域可生成与验证；凭据描述通过既有 system_credentials 边界分派，Windows 显式 unsupported，无 Mac helper 字段。保护存储/目录持久化、原生安装恢复、更新与 worker 操作在触碰资源之前经现有模块内的平台操作检查拒绝 Windows，不用 chmod/UID/fsync 代替 ACL。共享纯配置及配对契约、越权/降级拒绝和保护性拒绝在 Windows CI 验证；这些不是 Windows 安全后端或实际安装实现。当前不实现 Windows 凭据/启动/交付或扩大生产平台许可；这些须独立冻结并实机验收，不改生产提交确认语义。

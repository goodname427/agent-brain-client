# 0.5.7：Windows 宿主配置权限与安全恢复

0.5.6 安装和回滚错误地对 `.codex` 应用 Agent Brain 私有目录策略，遇到 Administrators owner 或宿主沙箱 ACL 可能失败。0.5.7 分开宿主配置与私有状态写入；密钥、注册、计划、身份、nonce 和恢复记录沿原私有策略保护，密钥不进入 TOML。

Windows 既有配置用数据读写句柄保留原文件对象，不读取或改写 owner、DACL、SACL，不要求审计权限；系统共享模式排除普通并发写入和重命名。新增配置继承宿主权限并以不覆盖方式发布，父目录不接管、不递归收紧。计划、包、来源、能力、摘要、原发行锚与路径检查不变，不添加全局沙箱白名单。

既有文件的数据写入不具备整文件原子性，读取者可能短暂看到部分内容。提交前持久记录计划、完整前像、后像及文件身份；恢复仅接受该计划的前缀覆盖／截断状态，回滚前另记录意图以支持回滚再次中断后的重试。外部编辑、对象替换及未知损坏保留审查。原密钥、设备身份、profile、旧包和全部恢复材料保留，不要求手改 ACL、PATH、摘要或重新配对。

本地隔离 Mac 回归 443 通过、19 平台跳过；新增故障注入覆盖部分写入、截断前中断、回滚再次中断、外部编辑与同字节对象替换。原生 Windows owner／DACL／共享句柄及正常入口恢复由正式 Windows 3.11／3.13 CI 验证；CI 结果独立记录，不等于用户实机成功。用户桌面、ARM64 实机、真实 Codex 重载及断电未测。

安装器和 Windows 运行包采用新的不可变 0.5.7；原 Windows stable 信任锚、文件／能力范围及 Server 政策不变，Mac 正式渠道不提升。正常入口取得最新官方源码后复用原身份恢复，无需重建密钥。原位写入与恢复的完整边界见 [技术说明](../../WINDOWS-HOST-CONFIG-WRITES.md)。

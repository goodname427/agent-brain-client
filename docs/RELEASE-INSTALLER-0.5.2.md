# Installer 0.5.2：正常入口与登记后中断恢复

0.5.2 修复 0.5.1 地址／密钥入口的两个问题：Windows 正常 bootstrap 创建的 installer-checkouts 缓存不再被误判为未知安装；registration 写入后、applying 回执完成前中断时，重跑正常入口可验证原绑定、计划和 journal 并恢复事务，无需 legacy connection 文件或新密钥。

缓存不被用作身份或发行授权。恢复只接受原连接、策略、设备／Codex 路径及 native 前后像；范围漂移或外部编辑保持阻断，身份、记忆和队列不被重置。Mac／Windows 仍共享协议及事务核心。

同时统一安装计划的 UTF-8 序列化摘要，修复中文等非 ASCII 用户路径下首次安装／重试的摘要不一致；OS 凭据记录的序列化和现有 profile pin 不变。

这是安装器源码修复，运行包与既有渠道不改。真实接入仍需服务端按具体范围启用，并将密钥私下交付至用户获准的本机安全位置。不会因本版本生成或重新生成真实密钥，不新增模型测试或目录授权。

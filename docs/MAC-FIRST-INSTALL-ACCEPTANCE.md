# Mac 首次安装收敛验收

已合入首次安装代码继续收敛为仓库脚本入口：删除 `.app` 构建器、整包复制/清单及复制后重新启动；保留必要依赖准备、无凭据配置、服务器/范围确认，并直接调用已有安全输入与 `install_once`。固定摘要 Python 仅在缺少兼容解释器时准备；标准本地 Git/Swift 工具缺失时请求工具安装后重跑，不给 Client 管理权限。

错误/过期邀请码恢复修复保留：只有明确拒绝并经重放与用户确认才清除 preparing；网络失败、丢 ACK 和重启保留原身份恢复记录。helper Swift 源码、现有信任摘要、21 文件 HTTPS 包及已交付 0.2.5 发布渠道均未更改。旧完整依赖策略保留校验；旧安装、worker、队列、快照与恢复材料保留。

隔离测试覆盖首次安装、必要依赖和 helper 一次准备、取消/Back/并发、格式错误/统一拒绝、未知结果、丢 ACK、配置与 executable 漂移、下载失败、摘要不符、归档越界、固定启动包准备中断恢复，以及原有内容/安装/更新全量回归。新增纯路径与注入配对契约覆盖 Windows 盘符、空格、分隔符、安全环境和同 code/nonce 恢复；Windows CI 只运行这些契约，不宣称 Windows 系统保护或安装已实现。

适用全量标准库测试、Ruff/mypy、无字节码语法检查、publication_check 和 helper 无 UI/Keychain 自检在隔离 HOME/CODEX_HOME 执行；最终 PR/main CI 另记录精确提交与结果。没有读取生产 Data、会话数据库、sessions 或旧混合仓构建源，未调用额外收费模型轮次。

源码安装路线不要求 Developer ID、公证或 Apple Team；真实 helper 要求是稳定用户路径、固定字节/源码摘要和原有 login Keychain 访问控制。裸机依赖准备、真实 UI/Keychain/MCP、Windows 后端/启动/平台许可及实机验收仍未完成；合成测试不能替代这些证据。本轮没有真实安装、发码、身份、凭据配置、发布或部署。

## 更新与 Onboard 当前轮次记录

黑盒起点仅给 Agent 普通用户短句：“帮我把 Agent Brain 更新到最新版，然后继续完成 Onboarding。”不要额外给内部类名、渠道实现或维护入口。确认 Agent 能从公开 README、安装说明及当前 MCP 指引找到 check-update/update；旧 worker 没有新指引时由公开仓库说明补足。此场景需独立实机执行；单元测试或文档存在不能替代 Agent 路由验收。

每次独立记录下列项目，不保留记忆正文或凭据：

| 项目 | 此次实际观察 |
| --- | --- |
| 轮次/UTC 起止 | 填当前轮次标识与时间 |
| 源码提交与入口 | 填本轮实际使用的提交、命令 |
| 原 policy 渠道/信任核验 | 填安全渠道名称及结果；不写私有路径或凭据 |
| check-update | 填 status、channel_checked、最新候选版本/commit；失败填原因，最新版未知 |
| update | 填 status、前后活动包版本/commit、是否改变、回滚/重试实际结果 |
| worker 重载 | 填宿主实际操作与 MCP client_runtime 版本/commit；未观测写未知 |
| 完整目录 | 填实际 kinds-only 参数、实际条目数、耗时与响应结果 |
| 本轮读取 | 填发起/成功/失败/取消/未读数与各阶段，HTTP 响应才填状态码 |
| 本轮重试 | 填实际重试数量、结果与版本；没有重试写 0 |
| Onboard 覆盖 | 填实际已读、重复、排除、冲突、待处理、不可访问及依据 |
| 历史参考 | 单独列旧轮次与计数，明确不是本轮结果 |

禁止仅凭 updated/current、包目录版本、旧完成标记或一次 catalog 成功宣布 worker 已加载或全量 Onboard 完成。check-update 的纯检查不得改变 active 指针；更新失败不能报告当前包是最新。运行中没有周期自动更新，本轮不验收该功能。没有正式发布的新源码指引不能被当作现有 worker 的行为。

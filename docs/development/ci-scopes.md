# Client 检查分层

PR 经正常代码审阅合入。仓库现有 **Client checks** 仍定义 PR、合并队列、main push 和手动触发。自动触发的调整由独立工作流改动处理。正式本地发布直接读取候选快检结果。

| 阶段 | 检查 |
| --- | --- |
| PR 和 main | 现有工作流可运行文档和定向检查。 |
| 正式发包前 | Mac 或 Windows 任一平台的同树快检，整套真实跑完不超过五分钟。详见[发布流程](release-pipeline.md)。 |
| 长回归 | 按需从本地命令或手动 **Client checks** 运行。包括全量发现、文档、源码、lint/type、Mac Swift helper 和 Windows 原生矩阵。 |
| 构建和发布 | 针对两个平台的四架构及统一安装器独立执行源码、版本、资产摘要、包 self-check、上传及读回校验。 |

[本地检查入口](../../dev/checks/client.py) 提供正式快检及独立长回归命令。源码快检原有的范围计划可用于开发定位。每次增加正式用例都要在参考 Mac 测整套并在 PR 写入选项和墙钟，超预算先优化或拆出长回归。

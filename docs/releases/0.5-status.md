## 0.5.8 与 0.5.9 补记

0.5.8 的安装器源码 tag 指向 `eb3b927`（PR #76），补齐 Windows 固定 launcher 交接、有限 Rule/Skill 映射、owned 全局 Hook 和未来来源选择，以及正常卸载／恢复的本地阶段。各阶段由 `installation_stages` 分别呈现；保留身份、队列和暂停设置，不把本地完成冒充模型加载。具体操作见 [安装阶段](../WINDOWS-INSTALL-CLOSURE.md)。

0.5.9 的源码基线包含 Windows 原生 `CODEX_HOME/memories` 有界导入（PR #77）与可重复发布流水线（PR #78）。现有记忆接口说明保持原文，见 [接口参考](../MEMORY-BEHAVIOR.md)；导入与未来 Hook 来源授权独立，不扩大到 `memories_v2`、SQLite 或会话历史。发布流程提供冻结输入、构建／校验、续传与读回，详见 [固定发布入口](../RELEASE-PIPELINE.md)。本次整理不执行其中发布动作。

0.5.0 产品 5.0 Windows 引入，以及安装器 0.5.1／0.5.2、组件 0.5.3–0.5.7 的历史说明见 [归档](../archive/README.md)。产品 5.0、Client 0.5.x 与既有产品 4.0 是不同编号，不相互替代。

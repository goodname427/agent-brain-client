# Installer 0.5.1：地址与长期接入密钥

本版本更新官方 main 的正常首次安装链。新设备只输入所选 HTTPS Server 地址，以及本机隐藏输入中的 Server 长期接入密钥；安装器自动取得平台配置、校验发行链、保存独立设备身份并完成原安装事务。Mac／Windows 共享接入协议与安装核心，各自使用 login Keychain／Credential Manager。无需 connection.json、独立摘要、ready 回执或邀请码。

长期密钥绑定明确的服务与授权范围，无默认到期，可由 Server 撤销或轮换；客户端不会把它当成系统或 Server 管理密钥。公开源码不含真实 endpoint、密钥或记忆。错误密钥可本机重填，网络/TLS/未知结果保留恢复；已撤销设备保留身份与未确认队列，停止并报告精确恢复需求。认证成功不等于本地事务完成。

这是安装器源码发布，运行包仍沿各设备原有已批准渠道发布和更新；安装器版本不冒充 active_package_version 或 running_worker_version。本次不重写旧 Mac 渠道、4.0 冻结标签或运行数据，不强制旧设备重装。不新增真实模型测试或来源授权。

服务端须部署对应地址／密钥协议、审核平台范围并在明确交付位置授权后生成真实密钥，普通用户再重跑 [正常步骤](ADDRESS-KEY-INSTALL.md)。源码发布本身不会启用生产访问；未启用的服务会失败并保留状态，不能退回让用户拼离线包。
